# المادة 25

أعوان الشرطة القضائية هم:

أولا: موظفو المصالح العاملة للشرطة بالمديرية العامة للأمن الوطني الذين ليست لهم صفة ضابط الشرطة القضائية؛

ثانيا: موظفو المصالح العاملة بالمديرية العامة لمراقبة التراب الوطني الذين ليست لهم صفة ضابط الشرطة القضائية؛

ثالثا: الدركيون الذين ليست لهم صفة ضابط الشرطة القضائية.
