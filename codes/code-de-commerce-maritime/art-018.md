# Article 18

Si, après délivrance de l'acte de nationalité, le bateau est changé dans sa forme, dans son tonnage ou de toute manière, le propriétaire est tenu d'obtenir un nouvel acte de nationalité, faute de quoi le bateau sera réputé étranger.
Il en est de même pour le bateau qui, par mesure exceptionnelle, est autorisée à changer de nom.
Dans les deux cas, le renouvellement de l'acte ne donne lieu qu'à la perception du prix du nouveau parchemin.
