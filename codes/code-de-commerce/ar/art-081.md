# المادة 81

ي ت م بيع الأصل التجاري أو تفويته وكذا تقديمه حصة في شركة أو تخصيصه بالقسمة أو بالمزاد، بعقد رسمي أو عرفي . ويودع ثمن البيع لدى جهة مؤهلة قانونا للاحتفاظ بالودائع . ينص العقد على:

.1 إسم البائع وتاريخ عقد التفويت ونوعيته وثمنه مع تمييز ثمن العناصر المعنوية والبضائع والمعدات؛

.2 حالة تقييد الامتيازات والرهون المقامة على الأصل؛

.3 وعند الاقتضاء، الكراء وتاريخه ومدته ومبلغ الكراء الحالي و إسم وعنوان المكري؛ .4مصدر ملكية الأصل التجاري.
