# Article 499

La saisie-gagerie est demandée par une requête, dans les mêmes formes que la saisie-exécution ; le saisi peut être constitué gardien. Les objets saisis ne peuvent, toutefois, être vendus qu'après que la saisie-gagerie a été validée par décision du tribunal de première instance du lieu où la saisie a été effectuée, le débiteur ayant été dûment appelé.
