# Article 87

Dans le cas où le tribunal, en présence d'une réclamation d'une partie, estime que la preuve de ses prétentions n'est pas entièrement rapportée, il peut déférer d'office le serment à cette partie par un jugement qui énonce les faits sur lesquels le serment sera reçu.
Ce serment est prêté dans les formes et les conditions prévues à l’article précèdent.
