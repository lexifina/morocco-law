# Article 232

Si l'inventaire est achevé, aucun scellé ne peut être apposé ; si l'inventaire est en cours, le scellé ne peut être apposé que sur les objets non inventoriés ; s'il n'y a aucun effet mobilier, le greffier dresse un procès-verbal de carence.
S'il y a des effets mobiliers qui soient nécessaires à l'usage des personnes qui restent dans la maison ou sur lesquels le scellé ne puisse être mis, le greffier dresse un procès-verbal contenant description sommaire desdits effets.
