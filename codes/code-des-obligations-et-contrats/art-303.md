# Article 303

Le tribunal peut, d'après les circonstances, ordonner a restitution des choses retenues par le créancier, si le débiteur offre de déposer entre les mains de ce dernier une chose ou valeur équivalente, ou de consigner la somme réclamée jusqu'à la solution du litige. Il peut aussi ordonner la restitution partielle de ces choses, dans les cas où elle peut se faire, lorsque le débiteur offre d'en déposer l'équivalent; l'offre d'une caution ne suffirait pas à libérer le gage.
