# Article 68
Lorsqu'une poursuite devant une juridiction répressive est de nature à entraîner la relégation, il est interdit, en application de l'article 76
- dernier alinéa - du code de procédure pénale, de recourir à la procédure de flagrant délit.
Les dispositions de l'article 311 du code de procédure pénale rendent obligatoire l'assistance d'un défenseur.
