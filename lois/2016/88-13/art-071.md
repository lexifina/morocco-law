# المادة 71

تطبق أحكام المادتين 104 و106 أدناه إذا تضمنت إحدى المطبوعات أو المطبوعات الدورية أو إحدى الصحف الإلكترونية إساءة للدين الإسلامي أو النظام الملكي أو تحريضا ضد الوحدة الترابية للمملكة. أو قذفا أو سبا أو مسا بالحياة الخاصة لشخص الملك أو لشخص ولي العهد أو لأعضاء الأسرة المالكة، أو إخلالا بواجب التوقير والاحترام لشخص الملك. كما تطبق أحكام هاتين المادتين إذا تضمنت إحدى المطبوعات أو المطبوعات الدورية أو إحدى الصحف الإلكترونية تحريضا مباشرا على ارتكاب جناية أو جنحة، أو تحريضا على التمييز أو على الكراهية بين الأشخاص.
